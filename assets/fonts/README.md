# Bundled code fonts

Regular faces are embedded by `BUNDLED_FONTS` in `src/app.rs`; no system install is needed.
The packaged app includes their license texts in `Contents/Resources/Licenses/`.

- Fira Code 6.2: `ttf/FiraCode-Regular.ttf` from [the official release](https://github.com/tonsky/FiraCode/releases/tag/6.2). License: `FiraCode-LICENSE.txt`.
- Source Code Pro 2.042: `TTF/SourceCodePro-Regular.ttf` from [Adobe's release](https://github.com/adobe-fonts/source-code-pro/releases/tag/2.042R-u%2F1.062R-i%2F1.026R-vf). License: `SourceCodePro-LICENSE.txt`.
- JetBrains Mono uses the existing `../JetBrainsMono-Regular.ttf` and `../OFL.txt`.
