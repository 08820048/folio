- 代码折叠（`⌥⌘[` / `⌥⌘]`）：折叠光标所在的最内层块，再按一次折叠外层；展开光标所在或所在行头部的已折叠块。行号槽旁的箭头只在光标行、鼠标悬停行与已折叠行出现，不是每个可折叠行都画。折叠掉的块完全不参与布局，所以原本在其中的光标会被移到仍然可见的那一行末尾。没有全部折叠 / 全部展开。折叠状态属于打开着的缓冲区，不跨重启保留。

- blame（`⌥⌘B`，View 菜单同名项）：编辑器下方一条薄栏显示光标所在行最后一次是谁改的——短哈希、作者、时间、提交摘要；未提交的行显示「Not committed yet」。跟随光标移动。只显示当前行而不是 gutter 一列，代码区宽度不受影响。读取的是**缓冲区文本**而不是磁盘文件：用 `git blame --contents` 把当前内容交给 git，所以编辑之后不会把下面的行错认到别的提交上。开关打开、切换文件、保存各读一次；其间的编辑会让它描述的是编辑前的行。
- 会话恢复：启动时把上次的会话放回来——按打开顺序恢复每个项目、各项目的标签顺序、当时正在看的那一个；路径已不存在的项目与文件在读取时直接丢弃，不会让整份会话失效。未保存的缓冲区每 5 秒写一次旁路文件，正常退出会把它删掉，所以留下来的只可能是崩溃 / 强退 / 断电那一次；下次启动把这些缓冲区连同未保存的编辑一起打开并标记为未保存（`⌘S` 照常走磁盘冲突检查），并提示恢复了几个文件。被恢复文件所属项目不在会话里时会丢弃。
- 列块多选（P2）：按住 `⌥` 拖动出一个矩形，或用 `⇧⌥↑` / `⇧⌥↓` 从光标逐行长出一列光标。矩形本身不是新的选区类型，而是每行一个选区、列范围相同，所以输入、删除、`⌘D`、`Esc` 都按多选区那套工作。行比矩形短时在该行行尾截止，不伸进下一行。任何移动或点击都会结束矩形，回到普通选区。列按字符计而不是按像素，遇到 tab 或宽字符时是一条文本列而非几何矩形。
- `.editorconfig`：打开文件时从文件所在目录向上找最近的 `.editorconfig`，遇到 `root = true` 停止，近的覆盖远的、同文件内后面的小节覆盖前面的；读 `indent_style`、`indent_size`、`tab_width` 三项决定该文件的缩进，没写到的回落到设置。`unset` 会清掉属性。`end_of_line`、`trim_trailing_whitespace`、`insert_final_newline` 是保存时的改写，本编辑器不做，所以直接忽略而不是做一半。glob 支持 `*`、`**`、`?`、`[...]`、`{a,b}`，数字区间 `{1..3}` 不展开。读取在后台线程随文件一起完成。
- 编辑器改为本地副本：`vendor/gpui-base` 是组件库中该 crate 的一份拷贝，根清单用 `[patch]` 只替换这一个包，其余依赖不变。代价是该 crate 自带的测试无法在本工作区运行，本项目自己的测试是改动它时唯一的网；重新 vendor 的步骤与清单改写要求记在 `vendor/README.md`。
- 多光标：`⌘D` 先选词再逐个加入下一处匹配，`⇧⌘L` 一次选中全部匹配（光标仍留在原处，视图不跳到最后一个），`⌥⌘↑` / `⌥⌘↓` 在上下行同列增加光标（从最外侧逐个长成块），`Esc` 收回成光标所在的那个。输入、粘贴、`⌫` / `⌦`、`Enter`（各自按所在行缩进）都作用于每一个选区；复制把各选区按行连接；整次编辑在撤销栈上只占一步，撤销也一次回来。选区上限 1000 个。点击或移动会把集合收敛成一个光标，所以不存在命令不知道的光标。括号在多光标下按普通字符逐个输入（没有唯一选区可包裹），`⌘/` 作用于首尾光标之间的整块。
- 内置终端（`⌘J`，View 菜单「Terminal」）：工作区下方一个可拖高度的抽屉，按项目记住标签。PTY 与 VT 解析交给 `alacritty_terminal`（和 Zed 同一套），本项目只画网格、把按键和鼠标编成字节写回去。中日韩输入源下可打印键先给 IME，上屏后再写入子进程（Zed 终端默认把键直接给 PTY，拼音组不起来）。收起抽屉不杀子进程；关掉最后一个标签或关掉项目才带走。终端持有键盘时 `⌘C` / `⌘V` / `⌘W` 只作用于它。图标用 Lucide 的 `square-terminal`。

## 尚待验收与已知边界

- 只读 LSP（hover / 跳转定义）实现过又移除（2026-09-11）：它只出现在需求文档「以后视需求」那条尾巴上，不在 MVP / v0.2 的承诺范围里，且把产品往 IDE 的方向拉，按定位决定不做。已把这一条从需求文档的「以后视需求」挪进「非目标」。曾经实现的提交是 `9dde6ca`（客户端在当时的 `src/lsp.rs`），要捡回来可以从那里 revert。
- Release 冷启动目标 ≤300ms，本机窗口测到 1048ms（2026-09-12），已记缺口、不改口径。滚动帧率仍未测。
- 09-11 这一轮（设置窗口、文件改动视图、标签页、行注释与括号配对、多光标）已在开发包里按清单逐项手工验收。验收中发现 `{}` 之间按回车不展开成三行，已修复并补了回归，修复后复验通过。
- 中文粘贴已验证。组合中 `Esc` 清拼音、上屏后 `⌘Z` 一次回到组合前已有自动测试；系统拼音候选窗位置仍要实机。
- Windows / Linux 的构建、快捷键、系统对话框和字体回退尚未实机验收。
- 高亮复用组件库的增量解析和超时后台处理；还没有单独完成 PRD 对可见区域高亮的性能审计。
- 32 MiB 文件上限；没有分块流式加载。符号链接暂不显示。UTF-8 以外的文本拒绝打开，避免有损保存。
- 新增语法以静态表编译进二进制，对启动、内存和滚动无影响，但 Release 二进制从约 21 MB 增至约 73 MB（OCaml 13.8 MB、Objective-C 11.4 MB、Haskell 8.1 MB、Git 提交信息 4.2 MB 最贵）。体积敏感时可删条目或整体关闭 `syntax` feature。
- 尚未覆盖的语言：Terraform / HCL 与 Julia 的 grammar crate 没有提供高亮查询，Groovy / Gradle / Jenkinsfile、GLSL、Perl、Nickel 的上游 crate 未导出查询；这些文件目前显示为纯文本。
- `.mli` 用 OCaml 实现语法高亮（上游只提供一份无法用于接口语法的查询）；`.m` 按约定归为 Objective-C，可能与 MATLAB 冲突。
- 快速打开是文件名子序列筛选，无相关度评分；结果上限 100。树/索引错误会显示提示。
- 多项目列表与会话一起持久化：重启后恢复每个项目、各项目的标签顺序与正在看的那一个（见上文「会话恢复」）。本节此前记的「只在本次会话内保留、重启后通过最近项目重新打开、不恢复未保存内容」是会话恢复落地之前的旧状态，已作废。
- 图片只读，暂不支持缩放、平移、动画播放；位图限制单边 16,384 像素及 32M 总像素。
- Git 状态在打开、切换项目、保存和磁盘监听后更新；忽略名单里的目录不刷树。
- 窗口位置暂未处理已断开的外接显示器；强制结束进程不保证恢复未保存缓冲。
- 仍需专门验证 Dock 的系统退出路径、系统关机路径、文件夹拖入；快速连续操作已有自动状态回归，原生手动压力验收仍待补充。
- 全局搜索没有流式结果和取消按钮：旧结果会在新扫描期间清空，输入很快时看不出，大仓库上会闪一下；扫描上限为 1000 处 / 200 个文件。
- 全局搜索不支持包含 / 排除路径过滤和搜索历史；命中行不可折叠。从结果打开文件后面板留着，`Esc` 才关。
- 多光标只覆盖上面列出的那些命令：没有 `⌥` 点击加光标，方向键等移动会把集合收敛成一个光标，词 / 行删除命令（`⌥⌫`、`⌥⌦`、`⌘⌫`、`⌘⌦`）保持原样、因此可能只作用于其中一个光标。撤销一次回退整次编辑，但不恢复当时的多个光标。选区上限 1000 个。
- 多光标的绘制（多个光标与多段选区高亮）没有自动覆盖，按键分发也没有。原因记在这里，免得再走一遍：测试执行器只在空窗口里构建元素树，不真正绘制，所以按键没有帧可解析；换成带根视图的窗口确实会绘制，但只要输入控件（编辑器就是输入）有焦点，gpui-component 就会向窗口要 `NSView` 去设 text content type，而测试窗口没有真实平台窗口，直接 panic。这条路径与括号、`⌘/` 在多光标下的表现一起留待实机验收。
- 侧栏显隐与 toast 都没有过渡动画：侧栏按宽度直接渲染，toast 是一个 2 秒后自行消失的浮层。需求文档 7.5 定的 120–160ms 侧栏动画与 toast 淡入淡出未做。
- 最近项目的时间是硬编码英文相对时间（`just now` / `N hours ago` / `N days ago`），没有按系统 locale 格式化，不足一小时一律显示 `just now`。界面语言本身固定英文，这一条与需求文档 8.6 的「日期按系统 locale」不符。
