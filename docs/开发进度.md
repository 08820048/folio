# Folio 开发进度

2026-09-11 更新。技术栈按用户确认保持 Rust + GPUI，无 Tauri / React / WebView。

## 已落地

- 原生 macOS 窗口、系统菜单和文件夹选择器、文件夹拖入入口。
- 复用组件库 TitleBar，在红绿灯右侧依次显示侧栏开关、项目 / 相对路径；取消居中标题和重复路径栏。窗口保留系统拖动与双击行为。
- 启动时读取系统外观，监听窗口外观变化，同步更新标题栏、侧栏、编辑器与弹层配色。
- 随系统切换的浅色 / 深色启动页、最近项目 JSON（最多 8 条）、失效路径标记、移除记录。
- 项目树懒加载和虚拟列表、键盘导航、可拖动侧栏、侧栏显隐。侧栏顶部显示当前项目文件夹名，点击或键盘操作可收起 / 展开整棵树，并保留子目录展开状态；已有回归断言覆盖。
- 文件名子序列匹配快速打开，结果使用虚拟列表；`:行号` 跳转。
- 全局搜索与替换：`⇧⌘F` 打开 `⌘P` 面板的内容模式，`⇧⌘H` 同时展开替换行。两种查找同属一个面板，标题栏只保留一个「全局搜索」按钮作为入口，去掉了重复的「快速打开」按钮（`⌘P` 和菜单项仍可进入文件名模式）。输入停下来 140ms 后在后台扫描索引到的文件，结果按文件分组、带行号与上下文预览，匹配片段用强调色标出。过滤器为 `Aa` 区分大小写（默认关）、`ab` 全字匹配、`.*` 正则（替换时支持 `$1` 捕获组）；三个过滤器同时作用于查找和替换。长行以命中处为中心截取并加省略号，裁掉前导缩进，Tab 展开为 4 空格。`↑ ↓` 选择、`Enter` 打开并把光标落在命中处、`Esc` 关闭。
- 「全部替换」先确认再执行，并区分文件状态：已打开的缓冲在内存中修改（保留撤销、变为未保存，由 `⌘S` 落盘），未打开的文件在后台原子写回。写回前会再校验磁盘内容与刚读出的一致，所以「读取→写入」窗口内的外部改动不会被覆盖；读取之前发生的改动会被读进来并在最新内容上替换。搜索用内存内容匹配已打开的文件，所以未保存的编辑不会让行列号错位；超过 2 MiB、二进制和非 UTF-8 文件静默跳过。
- 多项目会话：侧栏“添加项目”加入文件夹，根目录可收起并切换项目；各项目保留编辑实体、未保存内容、光标和目录展开状态。关闭项目只检查当前项目，退出检查所有项目。
- 单文件代码区；图片改为只读预览，支持 PNG / JPEG / GIF / WebP / BMP / TIFF / ICO / SVG，动画格式显示首帧。后台解码，保留透明度与纵横比。
- 应用图标统一使用 Lucide；图标按钮无背景框，保留提示、键盘操作和无障碍名称。界面规则记录在根目录 AGENTS.md。
- gpui-component 原生编辑器：Rope 文本缓冲、编辑/选区/剪贴板/撤销重做、文件内查找。
- Tree-sitter 白名单语言依赖、未知语言纯文本；JetBrains Mono 随二进制打包。
- 语法高亮从组件库内置的 37 种扩展到 60 种：`src/syntax.rs` 用 gpui-component 公开的 `LanguageRegistry` 再注册 23 种（XML、DTD、INI、Dockerfile、Nix、PowerShell、Fish、Vim script、Git 提交信息、正则、Vue、Dart、R、汇编、Solidity、Haskell、OCaml、Erlang、Elm、Gleam、SCSS、Less），不需要 fork 组件库。扩展名与整名映射集中在 `src/buffer.rs::language`，覆盖 `Dockerfile.dev`、`Containerfile`、`.zshrc`、`.editorconfig`、`Cargo.lock`、`.env.local` 等无扩展名或易误解的文件。
- 后台文件读取、目录索引和 Git CLI 状态；UI 不进行磁盘全量扫描。
- 保存前磁盘冲突检查、同目录临时文件原子替换、保留权限；保存失败保持脏状态。
- 关闭项目时检查当前项目脏缓冲，窗口和菜单退出时检查所有项目脏缓冲，提供保存 / 不保存 / 取消。
- 窗口退出时记录尺寸与位置，下次恢复。
- macOS `.app` 打包脚本与固定的 Rust / GPUI 依赖锁文件。
- 标题栏图标：侧栏开关改用 `panel-left-dashed` / `panel-right-dashed`。这两个图标组件库不自带，`src/assets.rs` 包装内置的 `AssetSource`，从 `assets/icons/` 提供并共用同一套 `icons/<name>.svg` 路径；`FolioIcon` 通过公开的 `IconNamed` trait 与内置 `IconName` 互换。
- 项目树右键菜单与文件操作：新建文件 / 文件夹、重命名、剪切 / 复制 / 粘贴、复制副本、在 Finder 中显示、在终端打开、在文件夹中查找、移到废纸篓（走 Finder，首次会弹自动化授权）、永久删除。写操作不覆盖已有条目，重命名支持仅大小写变化，删除整棵树走同一套确认。
- 界面语言固定为英文（`gpui_component::set_locale("en")`）。
- 设置窗口（`⌘,`）：字体、代码字体、字号、忽略目录等，写 JSON 后立即生效并作用于树与索引；表单由 `src/settings.rs` 读写，未知键保留。
- 文件改动视图（`⇧⌘D`）：相对于 HEAD 的统一 diff，带行号槽、增删标记与底色、hunk 头与计数；未跟踪文件整篇按新增显示；不在仓库或缺 git 时提示无内容可看。
- 标签页：每个打开的文件一个标签，条带 26px 且第二个文件才出现；未保存有标记，关闭时提供保存 / 不保存 / 取消；可拖动重排；右键菜单提供批量关闭与固定。
- 行注释（`⌘/`）与括号配对：注释标记按语言选择，写在缩进之后，整块已注释则取消；括号成对插入、选中即包裹、闭合符处跳过，规则与例外照搬 Zed。空括号对内按回车会把这一对铺成三行——光标落在中间那行、比开头多缩进一级，闭合括号另起一行对齐开头；其余位置回车只换行并按本行缩进。引号不在此列：引号里换行是分两行写字符串，不是写块。
- About 窗口，版本号取自 `Cargo.toml`。
- 代码折叠（`⌥⌘[` / `⌥⌘]`）：折叠光标所在的最内层块，再按一次折叠外层；展开光标所在或所在行头部的已折叠块。行号槽旁的箭头只在光标行、鼠标悬停行与已折叠行出现，不是每个可折叠行都画。折叠掉的块完全不参与布局，所以原本在其中的光标会被移到仍然可见的那一行末尾。没有全部折叠 / 全部展开。折叠状态属于打开着的缓冲区，不跨重启保留。
- 更新：没有做自动更新，也不是现在能做的——打包脚本只为本机做 ad-hoc 签名、没有 notarization，也就没有可供查询的 feed 与可下载的安装包。菜单里的「Check for Updates…」按原文的功能范围只做能诚实做到的那一半：打开版本列表页，让用户自己看。
- blame（`⌥⌘B`，View 菜单同名项）：编辑器下方一条薄栏显示光标所在行最后一次是谁改的——短哈希、作者、时间、提交摘要；未提交的行显示「Not committed yet」。跟随光标移动。只显示当前行而不是 gutter 一列，代码区宽度不受影响。读取的是**缓冲区文本**而不是磁盘文件：用 `git blame --contents` 把当前内容交给 git，所以编辑之后不会把下面的行错认到别的提交上。开关打开、切换文件、保存各读一次；其间的编辑会让它描述的是编辑前的行。
- 会话恢复：启动时把上次的会话放回来——按打开顺序恢复每个项目、各项目的标签顺序、当时正在看的那一个；路径已不存在的项目与文件在读取时直接丢弃，不会让整份会话失效。未保存的缓冲区每 5 秒写一次旁路文件，正常退出会把它删掉，所以留下来的只可能是崩溃 / 强退 / 断电那一次；下次启动把这些缓冲区连同未保存的编辑一起打开并标记为未保存（`⌘S` 照常走磁盘冲突检查），并提示恢复了几个文件。被恢复文件所属项目不在会话里时会丢弃。
- 列块多选（P2）：按住 `⌥` 拖动出一个矩形，或用 `⇧⌥↑` / `⇧⌥↓` 从光标逐行长出一列光标。矩形本身不是新的选区类型，而是每行一个选区、列范围相同，所以输入、删除、`⌘D`、`Esc` 都按多选区那套工作。行比矩形短时在该行行尾截止，不伸进下一行。任何移动或点击都会结束矩形，回到普通选区。列按字符计而不是按像素，遇到 tab 或宽字符时是一条文本列而非几何矩形。
- `.editorconfig`：打开文件时从文件所在目录向上找最近的 `.editorconfig`，遇到 `root = true` 停止，近的覆盖远的、同文件内后面的小节覆盖前面的；读 `indent_style`、`indent_size`、`tab_width` 三项决定该文件的缩进，没写到的回落到设置。`unset` 会清掉属性。`end_of_line`、`trim_trailing_whitespace`、`insert_final_newline` 是保存时的改写，本编辑器不做，所以直接忽略而不是做一半。glob 支持 `*`、`**`、`?`、`[...]`、`{a,b}`，数字区间 `{1..3}` 不展开。读取在后台线程随文件一起完成。
- 编辑器改为本地副本：`vendor/gpui-base` 是组件库中该 crate 的一份拷贝，根清单用 `[patch]` 只替换这一个包，其余依赖不变。代价是该 crate 自带的测试无法在本工作区运行，本项目自己的测试是改动它时唯一的网；重新 vendor 的步骤与清单改写要求记在 `vendor/README.md`。
- 多光标：`⌘D` 先选词再逐个加入下一处匹配，`⇧⌘L` 一次选中全部匹配（光标仍留在原处，视图不跳到最后一个），`⌥⌘↑` / `⌥⌘↓` 在上下行同列增加光标（从最外侧逐个长成块），`Esc` 收回成光标所在的那个。输入、粘贴、`⌫` / `⌦`、`Enter`（各自按所在行缩进）都作用于每一个选区；复制把各选区按行连接；整次编辑在撤销栈上只占一步，撤销也一次回来。选区上限 1000 个。点击或移动会把集合收敛成一个光标，所以不存在命令不知道的光标。括号在多光标下按普通字符逐个输入（没有唯一选区可包裹），`⌘/` 作用于首尾光标之间的整块。

## 尚待验收与已知边界

- 只读 LSP（hover / 跳转定义）实现过又移除（2026-09-11）：它只出现在需求文档「以后视需求」那条尾巴上，不在 MVP / v0.2 的承诺范围里，且把产品往 IDE 的方向拉，按定位决定不做。已把这一条从需求文档的「以后视需求」挪进「非目标」。曾经实现的提交是 `9dde6ca`（客户端在当时的 `src/lsp.rs`），要捡回来可以从那里 revert。
- Release 冷启动 300ms、文件读取 150ms、内存和刷新率指标尚无正式测量；不能据功能测试宣称达标。
- 09-11 这一轮（设置窗口、文件改动视图、标签页、行注释与括号配对、多光标）已在开发包里按清单逐项手工验收。验收中发现 `{}` 之间按回车不展开成三行，已修复并补了回归，修复后复验通过。
- 中文粘贴已验证，拼音输入法的候选窗、组合输入和撤销仍需专门人工验收。
- Windows / Linux 的构建、快捷键、系统对话框和字体回退尚未实机验收。
- 高亮复用组件库的增量解析和超时后台处理；还没有单独完成 PRD 对可见区域高亮的性能审计。
- 32 MiB 文件上限；没有分块流式加载。符号链接暂不显示。UTF-8 以外的文本拒绝打开，避免有损保存。
- 新增语法以静态表编译进二进制，对启动、内存和滚动无影响，但 Release 二进制从约 21 MB 增至约 73 MB（OCaml 13.8 MB、Objective-C 11.4 MB、Haskell 8.1 MB、Git 提交信息 4.2 MB 最贵）。体积敏感时可删条目或整体关闭 `syntax` feature。
- 尚未覆盖的语言：Terraform / HCL 与 Julia 的 grammar crate 没有提供高亮查询，Groovy / Gradle / Jenkinsfile、GLSL、Perl、Nickel 的上游 crate 未导出查询；这些文件目前显示为纯文本。
- `.mli` 用 OCaml 实现语法高亮（上游只提供一份无法用于接口语法的查询）；`.m` 按约定归为 Objective-C，可能与 MATLAB 冲突。
- 快速打开是文件名子序列筛选，无相关度评分；结果上限 100。树/索引错误会显示提示。
- 多项目列表当前只在本次会话内保留，重启后通过最近项目重新打开；不恢复未保存内容。
- 图片只读，暂不支持缩放、平移、动画播放；位图限制单边 16,384 像素及 32M 总像素。
- Git 状态在打开、切换项目和保存后更新，未接文件系统监听；外部修改在保存时检测。
- 窗口位置暂未处理已断开的外接显示器；强制结束进程不保证恢复未保存缓冲。
- 仍需专门验证 Dock 的系统退出路径、系统关机路径、文件夹拖入；快速连续操作已有自动状态回归，原生手动压力验收仍待补充。
- 全局搜索没有流式结果和取消按钮：旧结果会在新扫描期间清空，输入很快时看不出，大仓库上会闪一下；扫描上限为 1000 处 / 200 个文件。
- 全局搜索不支持包含 / 排除路径过滤和搜索历史；命中行不可折叠。从结果跳到文件会关闭面板，逐条检视需要重新打开。
- 多光标只覆盖上面列出的那些命令：没有 `⌥` 点击加光标，方向键等移动会把集合收敛成一个光标，词 / 行删除命令（`⌥⌫`、`⌥⌦`、`⌘⌫`、`⌘⌦`）保持原样、因此可能只作用于其中一个光标。撤销一次回退整次编辑，但不恢复当时的多个光标。选区上限 1000 个。
- 多光标的绘制（多个光标与多段选区高亮）没有自动覆盖，按键分发也没有。原因记在这里，免得再走一遍：测试执行器只在空窗口里构建元素树，不真正绘制，所以按键没有帧可解析；换成带根视图的窗口确实会绘制，但只要输入控件（编辑器就是输入）有焦点，gpui-component 就会向窗口要 `NSView` 去设 text content type，而测试窗口没有真实平台窗口，直接 panic。这条路径与括号、`⌘/` 在多光标下的表现一起留待实机验收。
- 编辑器仍未做块注释、行复制与行移动；它们属于后续版本。
