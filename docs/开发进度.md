# Folio 开发进度

2026-09-10 更新。技术栈按用户确认保持 Rust + GPUI，无 Tauri / React / WebView。

## 已落地

- 原生 macOS 窗口、系统菜单和文件夹选择器、文件夹拖入入口。
- 复用组件库 TitleBar，在红绿灯右侧依次显示侧栏开关、项目 / 相对路径；取消居中标题和重复路径栏。窗口保留系统拖动与双击行为。
- 启动时读取系统外观，监听窗口外观变化，同步更新标题栏、侧栏、编辑器与弹层配色。
- 随系统切换的浅色 / 深色启动页、最近项目 JSON（最多 8 条）、失效路径标记、移除记录。
- 项目树懒加载和虚拟列表、键盘导航、可拖动侧栏、侧栏显隐。侧栏顶部显示当前项目文件夹名，点击或键盘操作可收起 / 展开整棵树，并保留子目录展开状态；已有回归断言覆盖。
- 文件名子序列匹配快速打开，结果使用虚拟列表；`:行号` 跳转。
- 多项目会话：侧栏“添加项目”加入文件夹，根目录可收起并切换项目；各项目保留编辑实体、未保存内容、光标和目录展开状态。关闭项目只检查当前项目，退出检查所有项目。
- 单文件代码区；图片改为只读预览，支持 PNG / JPEG / GIF / WebP / BMP / TIFF / ICO / SVG，动画格式显示首帧。后台解码，保留透明度与纵横比。
- 应用图标统一使用 Lucide；图标按钮无背景框，保留提示、键盘操作和无障碍名称。界面规则记录在根目录 AGENTS.md。
- gpui-component 原生编辑器：Rope 文本缓冲、编辑/选区/剪贴板/撤销重做、文件内查找。
- Tree-sitter 白名单语言依赖、未知语言纯文本；JetBrains Mono 随二进制打包。
- 后台文件读取、目录索引和 Git CLI 状态；UI 不进行磁盘全量扫描。
- 保存前磁盘冲突检查、同目录临时文件原子替换、保留权限；保存失败保持脏状态。
- 关闭项目时检查当前项目脏缓冲，窗口和菜单退出时检查所有项目脏缓冲，提供保存 / 不保存 / 取消。
- 窗口退出时记录尺寸与位置，下次恢复。
- macOS `.app` 打包脚本与固定的 Rust / GPUI 依赖锁文件。

## 已检查

自动回归：`cargo test --locked --features desktop-tests`，共 6 个测试通过：2 个核心集成测试、2 个 GPUI 异步 / 多项目回归、1 个外观切换回归、1 个图片格式解码回归。`cargo clippy --locked --all-targets --features desktop-tests -- -D warnings` 通过。

状态修正：目录回调尊重最新收起状态；最近项目读写按请求顺序执行；项目切换/选择器期间阻止冲突操作；保存完成后重新检查新编辑；筛选重置滚动位置；侧栏在窗口外松开鼠标后停止拖动。

GPUI 状态回归使用真实编辑实体和测试执行器，隔离设置目录，不渲染原生输入控件；原生交互继续单独验收。

外观回归检查深 → 浅 → 深配色重设、编辑器/标题栏背景一致及透明标题栏选项。真实系统通知的切换仍需人工验收；本机浅色启动与文件打开已验证。

实际 macOS 开发包操作：

- 系统选择器打开独立测试项目，重启后从最近项目再次打开。
- `⌘P` 查找并打开 Rust 文件，语法高亮与中文显示。
- 全选、粘贴中文、多行编辑、`⌘S` 后检查磁盘内容正确。
- 保存后 `⌘Z` 恢复保存前内容并重新标记未保存。
- `⌘W` 和 `⌘Q` 弹出未保存确认；取消保留内容；全部保存后正常退出。
- `⌘F` 打开查找面板并输入查询，`⌘G` 跳转行，`⌘B` 切换侧栏。
- 展开含 2,500 个文件的目录，滚动后仅显示对应可见行。
- 打开约 6 MB / 60,000 行文本，显示关闭高亮提示，仍可切换侧栏。
- 打开 200,000 字符的超长单行，横向滚动及侧栏切换有响应。
- 独立开发窗口已验证 SVG 显示、左上角无框侧栏按钮、收起后紧邻根目录的“添加项目”按钮，以及添加第二个项目后切回恢复图片。
- Release 包构建及签名校验通过；本轮更新保留现有运行窗口，重启后生效。

## 尚待验收与已知边界

- Release 冷启动 300ms、文件读取 150ms、内存和刷新率指标尚无正式测量；不能据功能测试宣称达标。
- 中文粘贴已验证，拼音输入法的候选窗、组合输入和撤销仍需专门人工验收。
- Windows / Linux 的构建、快捷键、系统对话框和字体回退尚未实机验收。
- 高亮复用组件库的增量解析和超时后台处理；还没有单独完成 PRD 对可见区域高亮的性能审计。
- 32 MiB 文件上限；没有分块流式加载。符号链接暂不显示。UTF-8 以外的文本拒绝打开，避免有损保存。
- 快速打开是文件名子序列筛选，无相关度评分；结果上限 100。树/索引错误会显示提示。
- 多项目列表当前只在本次会话内保留，重启后通过最近项目重新打开；不恢复未保存内容。
- 图片只读，暂不支持缩放、平移、动画播放；位图限制单边 16,384 像素及 32M 总像素。
- Git 状态在打开、切换项目和保存后更新，未接文件系统监听；外部修改在保存时检测。
- 窗口位置暂未处理已断开的外接显示器；强制结束进程不保证恢复未保存缓冲。
- 仍需专门验证 Dock 的系统退出路径、系统关机路径、文件夹拖入；快速连续操作已有自动状态回归，原生手动压力验收仍待补充。
- 未做 diff、标签、项目搜索、设置、文件增删改名；它们属于后续版本。
