## 1. 背景与一句话定位

AI 写代码已经很普遍，开发者更多是：**打开仓库、读懂改动、做少量修正、确认后提交**。现有编辑器/IDE 为此过重：启动慢、界面满、内存高、功能密度远超「看 + 改几行」。

**本产品是一个小而精的桌面应用：用来打开项目、阅读代码、做有限编辑。不是 IDE，不是 Agent 工作台。**

体验目标：**安装后像启动器，打开项目后像一页纸。轻、薄、快、顺。**

---

## 2. 目标与非目标

### 2.1 目标

- 冷启动快，打开中小型仓库无明显等待
- 界面极简且精致，跟随系统浅色 / 深色
- 阅读代码舒适：高亮准确、滚动跟手、大文件不卡死
- 支持必要的少量编辑并可靠保存
- 支持按项目回顾最近打开记录，并恢复上次会话
- 单二进制分发，无浏览器内核

### 2.2 非目标（明确不做）

- 插件市场、主题商店、账号体系
- 调试器、测试运行器、任务系统
- 完整 REPL（内置终端已做：项目下的登录 shell，不是任务运行器）
- 实时协作、多人光标
- 内置 AI Agent / 补全云服务
- 远程开发、容器内编辑
- LSP：连只读的 hover / 跳转定义也不做，完整 LSP IDE（重构、Code Action、Inlay 全开）更不做
- 对标 VS Code / Cursor / Zed 的功能广度

---

## 3. 用户与场景

### 3.1 目标用户

- 用 AI 生成代码后，需要本地打开仓库做 review 的人
- 偶尔改配置、文案、一行逻辑的人
- 希望「打开看一下」而不想启动完整 IDE 的人

### 3.2 核心场景

1. 安装后第一次打开 → 选择文件夹打开项目
2. 再次打开 → 从最近项目进入，或直接恢复上次会话
3. 在文件树中浏览结构，打开源文件阅读；需要时同时看几个文件
4. `快速打开` 跳到某个文件
5. 阅读时滚动、搜索当前文件或整个项目、跳到指定行
6. 改几处内容，保存
7. 看 Git 改动（哪些文件脏了、当前文件 diff、当前行是谁改的）
8. 收起侧栏，全屏读代码

---

## 4. 产品原则

1. **功能能少就少**：多一个控件就要证明它每周都会被用到
2. **阅读优先，编辑够用**：光标、选区、撤销、保存必须稳
3. **可见即可用**：无欢迎广告、无更新新闻流、无扩展推荐
4. **性能是功能**：卡顿等于缺陷
5. **同一视觉语言**：启动页和工作区共用间距、圆角、字重、颜色
6. **默认即最佳**：用户不应先配字体、主题、插件才能用

---

## 5. 信息架构

应用只有两种顶层状态：

```
启动页  ←→  工作区
              ├─ 侧栏：项目树（可容纳多个项目）
              └─ 主区：标签条 + 代码 / 图片
                   └─ 可选：全屏代码（侧栏收起）
```

- **一个窗口，多个项目**：侧栏的「添加项目」可以把更多文件夹加进来，根目录可收起，可切换当前项目；每个项目保留自己的缓冲区、未保存内容、光标与目录展开状态。关闭项目只检查该项目，退出检查所有项目。
- **主区是标签条**：打开过的文件各占一个标签，第二个文件才出现标签条。
- 启动时把上次会话放回来；关掉全部项目回到启动页，进程不退出（除非用户关窗口）。

## 6. 功能需求

原定的 P0 / P1 / P2 分级已经走完：P0 与 v0.2 范围全部落地，P2 里除自动更新外也已落地。本节保留分级标注仅用于说明来源，未落地的条目在句内直接写明。

### 6.1 启动页（P0）

窗口打开后居中展示入口，无侧栏、无菜单墙。

- 主按钮：「打开项目…」→ 系统文件夹选择器
- 支持将文件夹拖入窗口打开
- 「最近项目」列表，最多 8 条
  - 显示：项目名（文件夹名）、完整路径、上次打开时间
  - 单击打开
  - 可「从列表移除」（不删磁盘文件）
- 无法访问的路径：标记失效，点击时提示并允许移除
- 记住窗口大小与位置；窗口几何在关窗与退出时写入，强制结束进程不保证保留

**不要**：账号登录、更新日志、示例仓库广告、模板向导。

### 6.2 打开 / 关闭项目（P0）

- 打开即该文件夹为 workspace 根目录
- 写入最近列表（已存在则置顶并更新时间）
- 关闭项目：释放该项目的文件缓冲与树缓存，回到启动页或下一个项目
- 忽略目录默认一份黑名单（`.git`、`node_modules`、`target`、`dist`、`build`、`.next`、`vendor`、`.DS_Store`），并可在设置里改
- **会话恢复**：启动时恢复上次打开的所有项目、各项目的标签顺序、正在看的那一个；路径已不存在的项目与文件在读取时直接丢弃。未保存的缓冲区每 5 秒写一次旁路文件，正常退出会删掉它，所以留下的只可能是崩溃 / 强退 / 断电那一次，下次启动连同未保存的编辑一起打开并标记为未保存。
- 多项目列表在会话里恢复，不再只活在本次会话内（原实现只保留到退出为止，已修复）。

### 6.3 工作区布局（P0）

- 左侧项目树，默认宽 240px，可拖拽调整（最小 160px，上限为窗口宽度的 40%）
- 右侧代码区占满剩余空间
- 顶栏极薄：侧栏开关、项目名 / 当前文件相对路径；标题栏用系统红绿灯，保留系统拖动与双击行为
- 底栏默认隐藏；保存成功等操作短暂 toast，不常驻状态栏
- 快捷键切换侧栏显隐（`⌘B` / `Ctrl+B`）
- 底部终端抽屉：`⌘J` / `Ctrl+J` 显隐，高度可拖（最小 120px，上限为窗口高度的 70%）。按项目记住标签；收起不杀进程；关掉最后一个标签或关掉项目才带走子进程。终端持有键盘时 `⌘C` / `⌘V` 复制粘贴其选区，`⌘W` 关掉当前标签——别处这三键仍是编辑器的。
- 全屏代码模式：侧栏收起后代码区占满整宽，不额外加左右内边距（侧栏与 3px 拖拽条一起从布局中移除）

**未实现**：侧栏显隐与 toast 都是瞬时出现、瞬时消失，没有过渡动画（见 7.5）。

### 6.4 项目树（P0，文件操作来自 P1）

- 懒加载展开文件夹
- 文件 / 文件夹两种图标即可，不引入图标包（图标统一用 Lucide）
- 当前打开文件高亮
- 单击文件：打开（已打开则聚焦）；单击文件夹：展开 / 折叠
- 键盘：上下移动、Enter 打开 / 展开、左折叠、右展开
- 虚拟列表：大目录只渲染可见行
- Git 状态：已修改 / 未跟踪在文件名旁用极淡色点或左侧色条表示；根目录不是 git 仓库时静默当普通文件夹
- 项目头可收起 / 展开整棵树，并保留子目录展开状态
- **右键菜单与文件操作**（原 P1，已实现）：新建文件 / 文件夹、重命名、剪切 / 复制 / 粘贴、复制副本、在 Finder 中显示、在终端打开、在文件夹中查找、移到废纸篓（走 Finder，首次会弹自动化授权）、永久删除。写操作不覆盖已有条目，重命名支持仅大小写变化，删除整棵树走同一套确认。
- 仍未做：拖拽移动文件。

### 6.5 打开文件与标签（P0 + P1）

- `⌘P` / `Ctrl+P`：按文件名子序列匹配并打开（排除忽略目录），结果用虚拟列表，上限 100 条，无相关度评分；输入 `:行号` 跳转
- 打开过的文件保留在内存，切回不丢光标与撤销历史（会话内）
- **多标签**（原 P1 可选，已实现并作为默认形态）：每个打开的文件一个标签，条带 26px 且第二个文件才出现；未保存有标记，关闭时提供保存 / 不保存 / 取消；可拖动重排；右键菜单提供批量关闭与固定
- **图片**：PNG / JPEG / GIF / WebP / BMP / TIFF / ICO / SVG 以只读预览打开，后台解码，保留透明度与纵横比，动画格式显示首帧；不支持缩放、平移与动画播放

### 6.6 代码阅读（P0）

- 等宽字体显示；中西文混排用自带的 CJK 回退字体链对齐（字体策略见 7.4）
- 行号
- 当前行背景微弱高亮
- 语法高亮（Tree-sitter），按扩展名加载 grammar；组件库内置 37 种，本项目在 `src/syntax.rs` 再注册 23 种，共 60 种
- MVP 语言白名单（Rust、TypeScript / JavaScript、Python、Go、JSON、TOML、Markdown、YAML、HTML/CSS）已全覆盖；未覆盖的语言显示为纯文本，不高亮也不报错
- 超长行可横向滚动且不冻结 UI
- 二进制 / 明显非文本：不按文本打开，提示无法预览
- 大文件：超过 5 MiB 关闭高亮，超过 32 MiB 拒绝打开（无分块流式加载）
- **软换行固定关闭**：不提供开关，长行一律横向滚动
- 符号链接不显示；非 UTF-8 文本拒绝打开，避免有损保存

### 6.7 代码编辑（P0，P1 / P2 均已落地）

必须稳定：

- 插入、删除、换行、Tab（空格缩进，默认 4，可按语言 2）
- 方向键、Home/End、PageUp/PageDown
- 鼠标点击定位、拖拽选区
- 复制 / 剪切 / 粘贴（中文粘贴已验证）
- 全选
- 撤销 / 重做
- 保存 `⌘S` / `Ctrl+S`；未保存在标签上显示标记；保存前做磁盘冲突检查，同目录临时文件原子替换并保留权限，失败则保持脏状态
- 关闭标签、关闭项目或退出应用时若有未保存：对话框（保存 / 不保存 / 取消）。关闭项目只检查当前项目，退出检查所有项目。
- `.editorconfig`：打开文件时向上找最近的配置，读 `indent_style`、`indent_size`、`tab_width` 决定该文件缩进；`root = true` 停止上溯，近的覆盖远的、同文件内后面的小节覆盖前面的；`unset` 清掉属性。`end_of_line`、`trim_trailing_whitespace`、`insert_final_newline` 是保存时的改写，本编辑器不做，因此直接忽略；`{1..3}` 这类数字区间不展开

已实现的原 P1 / P2 项：

- 行注释（`⌘/`）与括号配对：注释标记按语言选择，写在缩进之后，整块已注释则取消；括号成对插入、选中即包裹、闭合符处跳过；空括号对内按回车铺成三行
- 多光标：`⌘D` 逐个加入下一处匹配，`⇧⌘L` 一次选中全部匹配，`⌥⌘↑` / `⌥⌘↓` 在上下行同列增加光标，`Esc` 收回。输入、粘贴、`⌫` / `⌦`、`Enter` 作用于每一个选区；整次编辑在撤销栈上只占一步。上限 1000 个选区。未覆盖：`⌥` 点击加光标、方向键移动多光标、词 / 行删除命令（`⌥⌫`、`⌥⌦`、`⌘⌫`、`⌘⌦`）
- 代码折叠（`⌥⌘[` / `⌥⌘]`）：折叠光标所在的最内层块，再按一次折叠外层；没有全部折叠 / 全部展开，折叠状态不跨重启保留
- 列块多选（`⇧⌥↑` / `⇧⌥↓`，或按住 `⌥` 拖动）：每行一个选区、列范围相同，列按字符计而非按像素

仍未做：块注释、行复制、行移动。

### 6.8 搜索（P0 + P1）

**当前文件（P0）**

- `⌘F` 查找，上一个 / 下一个，高亮匹配
- `⌥⌘F` 替换
- 跳转到行 `⌘G`，或命令框输入 `:123`

**项目内（P1，已实现）**

- `⇧⌘F` 打开 `⌘P` 面板的内容模式，`⇧⌘H` 同时展开替换行；两种查找同属一个面板，标题栏只保留一个「全局搜索」按钮
- 输入停下 140ms 后在后台扫描已索引的文件，结果按文件分组、带行号与上下文预览，匹配片段用强调色标出
- 过滤器：`Aa` 区分大小写（默认关）、`ab` 全字匹配、`.*` 正则（替换支持 `$1` 捕获组），三个过滤器同时作用于查找和替换
- `↑ ↓` 选择，`Enter` 打开并把光标落在命中处，`Esc` 关闭；`← →` 在查询框光标贴住对应一侧边界时（`→` 在文本末尾、`←` 在开头，且没有选中文字）切换 Files / Contents 两个模式页，光标在文本中间或焦点不在面板输入框时保持移动光标的本义
- 「全部替换」先确认再执行，并区分文件状态：已打开的缓冲在内存中修改（保留撤销、变为未保存），未打开的文件在后台原子写回，写回前再校验磁盘内容一致

**实现说明**：项目内搜索是自研的后台扫描，**不调用 ripgrep**（原技术选型为 ripgrep，实际未采用）。因此带有以下边界：

- 无流式结果与取消按钮，旧结果在新扫描期间清空，大仓库上会闪一下
- 扫描上限 1000 处 / 200 个文件
- 超过 2 MiB、二进制、非 UTF-8 的文件跳过
- 不支持包含 / 排除路径过滤，没有搜索历史，命中行不可折叠

### 6.9 Git（P0 + P1）

**状态（P0）**

- 根目录是 git 仓库时扫描工作区状态，树节点着色；无 git 则静默当普通文件夹
- 在打开、切换项目和保存后更新；**未接文件系统监听**，外部修改在保存时检测

**diff（P1，已实现）**

- `⇧⌘D` 打开文件改动视图：相对 HEAD 的统一 diff，带行号槽、增删标记与底色、hunk 头与计数
- 未跟踪文件整篇按新增显示；不在仓库或缺 git 时提示无内容可看
- 只做统一 diff，没有并排视图；计数按行数，改一行读作「删一行、加一行」

**blame（P1，已实现）**

- `⌥⌘B` 在编辑器下方显示光标所在行最后一次是谁改的：短哈希、作者、时间、提交摘要；未提交的行显示「Not committed yet」
- 只显示当前行而不是 gutter 一列，代码区宽度不受影响
- 读的是**缓冲区文本**而不是磁盘文件（`git blame --contents`），编辑之后不会把下面的行错认到别的提交上；开关打开、切换文件、保存各读一次

不做 commit / push / 解决冲突。

### 6.10 设置（P1，已实现）

`⌘,` 打开**独立设置窗口**（不是覆盖在编辑器上的面板），标题栏由应用自绘以匹配主题。侧栏是树，四个标题可折叠，五个页面：界面字体与字号、代码字体与字号、Tab 大小与缩进字符、侧栏是否默认打开、树与搜索跳过的文件夹名。

- 改动立即生效；字号与字体即时应用，Tab 大小只对之后打开的生效
- 忽略目录改动会重读树并重建快速打开索引
- 写入本地 JSON，不联网；未知键保留；手改的文件按范围钳制而不是拒绝，损坏的文件报告而不是覆盖
- 项目自己的 `.editorconfig` 对该项目覆盖的文件有最终决定权

### 6.11 更新与关于（P2）

- **关于**：独立窗口，版本号取自 `Cargo.toml`。已实现。
- **自动更新：未实现，且当前条件下做不了**。打包脚本只为本机做 ad-hoc 签名、没有 notarization，既没有可供查询的 feed，也没有可下载的安装包。菜单里的「Check for Updates…」按原文的功能范围只做能诚实做到的那一半：打开版本列表页，让用户自己看。

## 7. 交互与视觉规范

### 7.1 气质

安静、留白、对比克制。像阅读工具，不像仪表盘。

### 7.2 结构尺寸

- 网格：8px
- 主窗口默认 960×680、最小 640×480；设置窗口默认 918×683、最小 460×360。两者都记住用户调整后的位置与大小（写 `window.json`）。启动页与工作区共用同一个窗口，没有单独的启动页尺寸。
- 树行高：27px；标签条：26px（第二个文件才出现）
- 顶栏用组件库的 TitleBar，外观自绘，高度由组件库决定，本项目未自定义
- 代码字号：默认 14（可设 10–24）；界面字号：默认 13（可设 10–20）
- 行高与圆角按组件库主题走；「启动页卡片 12px、按钮 8px」是设计意图，未逐项核对

### 7.3 颜色

只保留一层背景、一层表面、一条极淡分割线、一种强调色。跟随系统浅色 / 深色，窗口外观变化时同步更新标题栏、侧栏、编辑器与弹层配色。

- 窗口背景略深
- 树与代码区几乎同色，分割线 alpha 很低
- 选区、当前行、匹配项对比清晰但不要霓虹
- Git：修改一种色、新增一种色，饱和度低

滚动条：默认隐藏或极细，滚动时出现。

### 7.4 字体

- 代码：JetBrains Mono，随二进制打包（许可见 `assets/OFL.txt`）
- 中文回退：应用自设字体链，把等宽 CJK 家族放在最前，不依赖 GPUI 自带的回退栈（后者只列 `.ZedMono`、`Helvetica`、`Segoe UI` 等，没有任何 CJK 家族，会让汉字落到比例字体上、破坏字符网格）
- UI 文案用同一等宽或稍紧的无衬线，界面语言固定英文

### 7.5 动效

只允许短、功能性动效。

**现状：侧栏显隐和 toast 都是瞬时的**——侧栏直接按宽度渲染，toast 是一个定时消失的浮层，两者都没有过渡动画。原定的「侧栏 120–160ms」「Toast 淡入淡出」尚未实现。

明确禁止：大面积弹性、视差、启动页复杂动画。

## 8. 非功能需求

### 8.1 性能（首发验收线——**尚未测量**）

在主流笔记本（8GB+、集成显卡）上：

| 指标 | 目标 | 状态 |
|---|---|---|
| 冷启动到启动页可点击 | ≤ 300ms（Release） | 未测量 |
| 打开含 1 千～1 万文件的仓库到树可交互 | ≤ 500ms（忽略目录已排除） | 未测量 |
| 打开 ≤ 1MB 源文件到可阅读 | ≤ 150ms | 未测量 |
| 空闲内存（启动页） | 尽量 < 80MB | 未测量 |
| 打开普通项目阅读时 | 尽量 < 150MB | 未测量 |
| 滚动 | 跟随显示器刷新，无明显掉帧 | 未测量 |
| 超长单行 / 数万行文件 | 不锁死 UI；可降级高亮 | 手工验过不锁死，无帧率测量 |

不能据功能测试宣称达标。UI 线程禁止做：磁盘全量扫描、全文件 parse、git status 全量阻塞、项目搜索扫描——目前都由后台任务承担。

### 8.2 平台

- **macOS**：开发与打磨主平台，已实现并逐项人工验收
- **Windows / Linux**：代码路径已写（Wayland + X11、Recycle Bin / `gio trash` 等），**未实机验收**，快捷键、系统对话框与字体回退均待验证
- 单窗口应用
- 高 DPI：未专门验收
- **输入法**：中文粘贴已验证；拼音输入法的候选窗、组合输入与撤销仍需专门人工验收（P0 编辑场景验收项）

### 8.3 可靠性

- 打开失败、权限不足、文件在外部被删：提示，不崩溃
- **外部修改当前文件**：只在保存时检测，磁盘内容与读入时不一致则拒绝覆盖并保持脏状态；阅读期间不做提示（原 P1 项的主动提示未实现）
- **崩溃恢复**：未保存的缓冲区每 5 秒写旁路文件，崩溃 / 强退 / 断电后下次启动连同编辑一起恢复（原计划放在 v0.2 之后，已提前实现）。强制结束进程不保证恢复

### 8.4 安全与隐私

- 无账号、默认无网络；唯一的网络行为是「Check for Updates」打开版本页（由用户点击触发）
- 不上传代码
- 最近项目、会话、未保存缓冲、设置、窗口几何都只存本地路径与内容，不出机器

### 8.5 无障碍（P1——**未验收**）

- 系统缩放不糊：未专门验收
- 键盘可完成打开项目、打开文件、保存、关项目：菜单与快捷键齐全，未做过纯键盘全流程验收
- 对比度达到可读：未做过量化检查，不强求完整读屏

### 8.6 国际化

- 界面语言**固定英文**（`gpui_component::set_locale("en")`），不跟随系统语言
- 最近项目的时间是英文相对时间（`just now` / `N hours ago` / `N days ago`），**未走系统 locale**
- 代码内容按文件原样显示；文件树与路径按原样

## 9. 技术架构约束

### 9.1 技术栈

| 层 | 选择 |
|---|---|
| 语言 | Rust 1.95.0（`rust-toolchain.toml` 钉死） |
| UI | GPUI + `gpui_platform`（git 依赖，版本锁在 `Cargo.lock`） |
| 组件 | gpui-component（钉 rev `f3ba893`）；其中 `gpui-base` 用根清单的 `[patch]` 换成本地 `vendor/gpui-base` 一份拷贝 |
| 文本缓冲 | 组件库编辑器的 Rope |
| 高亮 | Tree-sitter，组件库增量解析 + 超时后台处理；`src/syntax.rs` 再注册 23 种语法 |
| 项目搜索 | 自研后台扫描（**不是 ripgrep**，原选型未采用） |
| Git | 调用 git CLI（status / diff / blame） |
| 本地存储 | JSON：最近项目、会话、未保存缓冲、设置、窗口几何 |

禁止：Electron、Tauri/WebView、把 Zed 整仓当依赖。

**已知代价**：语法表静态编进二进制，Release 体积从约 21 MB 增至约 73 MB（OCaml 13.8 MB、Objective-C 11.4 MB、Haskell 8.1 MB、Git 提交信息 4.2 MB 最贵），体积敏感时可删条目或整体关闭 `syntax` feature。`vendor/gpui-base` 让该 crate 自带的测试无法在本工作区运行，本项目自己的测试是改动它时唯一的网。

### 9.2 模块（现状）

- `app`（`src/app.rs`）：进程、窗口、启动页 / 工作区 / 设置 / 关于、菜单与命令分发
- `workspace` / `tree` / `recent` / `session`：根路径、树、最近项目、会话与崩溃恢复
- `buffer` / `editorconfig` / `syntax` / `preview`：文件读取与语言判定、缩进配置、语法注册、图片解码
- `search` / `git` / `diff` / `blame`：后台任务，结果回 UI
- `fs_op` / `settings`：文件操作与设置读写
- `assets`：图标资源

**偏离原计划**：原定的 `core`（buffer / 光标 / 撤销）与 `editor`（代码视口）两个模块没有自研实现，直接复用 gpui-component 的编辑器，改动落在 `vendor/gpui-base`；`theme` 用的是组件库的主题系统。`src/app.rs` 已有约 9,300 行，是当前最大的单文件，后续功能增长前应考虑拆分。

硬规则：UI 只渲染快照；变更走命令。

### 9.3 GPUI 使用约定

- 文件树、搜索结果、代码行一律虚拟列表
- 钉 GPUI 版本与组件库 rev，升级单独排期
- 不复制 Zed 的 `editor` / `language` 整套 crate

## 10. 版本划分

### 已交付

**v0.1（MVP）**：启动页 + 最近项目 + 打开文件夹 + 树 + 单文件阅读 + Tree-sitter 白名单高亮 + 基本编辑与保存 + 文件内查找 + 快速打开 + 侧栏显隐 + Git 脏标记。

**v0.2**：项目搜索与替换、多标签、文件增删改名、diff、设置、blame、多光标、代码折叠、列块多选、行注释与括号配对、`.editorconfig`、图片预览、多项目会话与崩溃恢复、关于窗口。

### 尚未实现

按重要性排序：

1. **性能测量**——8.1 全部指标没有正式测量，这是 MVP 能否算完成的判定前提
2. **IME 专门验收**——拼音输入法的候选窗、组合输入、撤销
3. **Windows / Linux 实机验收**——构建、快捷键、系统对话框、字体回退
4. **无障碍验收**——系统缩放、纯键盘全流程、对比度
5. **软换行开关**——目前固定关闭
6. **侧栏与 toast 动效**——目前都是瞬时
7. **locale 化的日期**——目前是硬编码英文相对时间
8. **阅读期的外部修改提示**——目前只在保存时发现冲突
9. **搜索的流式结果、取消、路径过滤、搜索历史**
10. **块注释、行复制、行移动**
11. **大文件分块加载**——目前 32 MiB 上限
12. **自动更新**——受限于发布链路（ad-hoc 签名、无 notarization），不是编辑器内的活

### 明确不做

LSP、插件、AI 服务、调试器、多窗口多仓库、commit / push。完整 REPL / 任务运行器也不做；项目下的登录 shell 已经在抽屉里。

## 13. 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| GPUI API 不稳定 | 升级成本高 | 钉版本与组件库 rev；壳与 core 分离 |

## 14. 已决问题

1. **首发是否只做 macOS？** —— 先 macOS：它已实现并逐项验收；Windows / Linux 代码路径已写，待实机验收。
2. **界面语言默认中文还是英文？** —— 固定英文，不跟随系统语言。
3. **Tab 默认 2 还是 4？是否跟 `.editorconfig`？** —— 默认 4，按语言可能是 2；项目里的 `.editorconfig` 对该项目覆盖的文件有最终决定权。
4. **未保存缓冲要不要做崩溃恢复？** —— 已做（每 5 秒旁路文件），比原计划提前。
5. **产品名与图标？** —— Folio，图标用 Lucide 集。
