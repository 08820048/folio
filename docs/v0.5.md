# Folio v0.5

2026-09-12。v0.4 阅读式 review 已经实机走过。这一轮补 **分屏**：两个文件同时开着时，不必在标签之间来回切。

入口对齐 Zed：标签栏最右侧的分屏按钮，点开四向菜单。系统 View 菜单不再放分屏。

原则仍是需求文档第 4 节：功能能少就少；阅读优先。Zed 的无限网格、同一文件两个视口仍不做。Folio 最多两栏，可左右或上下。

## 不做

- 超过两栏、递归网格
- 同一文件出现在两栏（一份 `EditorState` 不能画两次，复制一份会和脏标记脱节）
- 分屏比例写入会话
- 标签栏上的 New / Zoom（Zed 那一排另外两个按钮）
- stage / commit / push、LSP、AI、插件

## 做

### 1. 标签栏右侧入口

有文件的栏都画标签条，右侧一颗 Lucide `gap-horizontal`，无背景框。点开浮层：

- Split Right — `⌘K →`
- Split Left — `⌘K ←`
- Split Up — `⌘K ↑`
- Split Down — `⌘K ↓`

`⌘\` 仍是向右切开（VS Code / Zed 习惯）。`⌘K` 再按方向键走同一套。已经是两栏再选一个方向：把另一栏转到那一侧，不第三栏。

关掉一栏最后一个文件，两栏并回一栏。

### 2. 打开与焦点

树 / `⌘P` / 搜索打开的文件进焦点栏。若该文件已在另一栏，只切焦点，不复制标签。`⌘⌥←` / `⌘⌥→`（以及 `⌘⌥↑` / `⌘⌥↓`）切栏；点编辑器也切。`⌘W` 仍关项目。

两个标签并排后各占一栏；只有一个文件时，新开的那栏空着，一句 `Open a file`。

中间一条可拖的分隔线，默认对半。左右是竖线，上下是横线。标签可以拖到另一栏的条带或编辑区；落到空栏上就过去，拖走一栏最后一个文件则并回一栏。

### 3. 会话

`session.json` 的 `right_tabs` / `right_active` 仍是第二栏。可选 `split_vertical`：旧会话没有这个键，按左右恢复。

`⇧⌘D` 与图片预览跟焦点栏的那个文件，不盖住另一栏。

## 验收

- 开着 A，标签栏右侧能看见分屏按钮；点开是四向，不在系统菜单里
- 开着 A、B，在 A 上 Split Right，左右同时看见两份，互不影响滚动
- Split Down 改成上下两栏
- 再打开 C，进焦点栏
- 关掉一栏最后一个文件，回到单栏，标签都在
- 重启后两栏还在；上下切过的会话按上下回来
- `⌘\` 与 `⌘K →` 都是向右切
- 左栏一个标签拖到右栏条带，文件出现在右栏并离开左栏；再拖回去也能换回来

## 停手

两栏能切左右或上下、入口在标签栏、能恢复就停。不要接着做第三栏或同一文件对开。
