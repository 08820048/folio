# Folio v0.3

2026-09-12。范围来自产品判断：v0.2 功能面已经够用，这一轮不扩表面，只补**阅读闭环里还卡手的地方**。

原则仍是需求文档第 4 节：功能能少就少；阅读优先；默认即最佳。下面「做」的每一条都要能说清每周为什么会用到。

## 不做

- LSP、补全、调试、任务、commit / push、插件、AI
- 自动更新、大文件分块加载、侧栏 / toast 动效、日期 locale
- 搜索的流式结果、取消、路径过滤、搜索历史（本轮只修「跳转后面板关掉」）
- Windows / Linux 实机验收、无障碍量化（另排，不挡 v0.3）

## 做（按顺序）

### 1. 阅读期的外部修改

磁盘上的文件变了，Folio 还开着时要能看见。典型场景：AI 刚写完，人在 Folio 里读。

- 监听当前打开的每个项目根目录（忽略名单里的目录不进树刷新）
- 事件合并后再处理，避免保存自己的文件时抖一下
- 已缓存的文件夹重新读子项；Git 脏标记跟着刷新
- 已打开、**没有未保存编辑**的文件：直接重载，toast 一句 `Reloaded from disk`
- 已打开、**有未保存编辑**的文件：编辑器上方一条提示，`Reload` 丢掉本地编辑并重载，`Keep` 继续改（保存时仍走原来的冲突检查）
- 磁盘上的文件被删：有未保存编辑则不丢缓冲，只提示；干净的缓冲提示后保持打开

验收：在 Folio 外改一个打开着的干净文件，编辑器内容更新；改一个脏文件，出现提示且 `Keep` 不丢字。**已落地**（自动测试覆盖干净重载 / 脏提示 / Reload）。

### 2. 性能测量

不能再口头说「轻」。做一份可重复的记录，不是新 UI。

- Release 下量：冷启动到启动页可点、打开 1 千～1 万文件仓库到树可交互、打开 ≤ 1MB 源文件到可阅读、启动页与阅读时的内存
- 数字写进 `docs/开发进度.md`，对得上需求文档 8.1 的表
- 达不到目标就记缺口，不改口径
- `FOLIO_PERF=1` 打首帧、打开树、索引、打开文件和 `rss_mb`。`FOLIO_PERF_QUIT=1` 首帧后再等 2 秒退出，方便复跑。

验收：表里每一格有一次本机数字和日期，不再是「未测量」。**已量**（2026-09-12 Release，本机窗口）：首帧 1048ms / 77 MB（目标 ≤300ms，未达标，不改口径）；会话恢复后阅读约 124 MB（目标 <150MB）；根目录列出 276ms（40 项）、索引 564 文件 28ms；打开 ≤29KB 源文件 4–50ms。后台：2501 文件索引 2.8ms、1MB 读盘 0.2ms。滚动帧率仍未测。

### 3. 编辑器中文输入法

终端已经能看见正在打的字。编辑器走同一条验收。

- 拼音组合、候选窗位置、上屏、组合中途 `Esc` / `⌫`
- 上屏后 `⌘Z` 一次回到组合前
- 中英切换后立刻能继续打

验收：在编辑器里用系统拼音走完上面几条，不丢字、不丢光标。有 bug 就修，没有就在进度里记「已验收」。**代码路径已落地**：组合中 `Esc` 删掉标记文字（不再只去掉下划线），Folio 也不会先拿去关搜索 / 退出 diff；上屏后 `⌘Z` 一次回到组合前。自动测试走 `replace_and_mark` / `replace_text_in_range` / `undo` / `escape`。系统拼音候选窗位置仍要实机走一遍。

### 4. 文件树拖拽移动

右键增删改已经有了，缺的是把手里的文件放到另一个文件夹。

- 拖一条树行到文件夹上：移动（同卷 rename，跨卷复制后删）
- 拖到文件上：落到它所在的文件夹
- 不覆盖已有同名条目；不能拖进自己的子孙
- 打开着的缓冲跟着路径走，未保存内容留下
- 多项目之间可以拖

验收：把文件拖进子文件夹，树、标签路径、未保存编辑都还在。**已落地**（自动测试：拖进子目录后脏缓冲跟着走）。

### 5. 行复制、行移动、块注释

改几行时的肌肉记忆。

- 行复制：`⇧⌘D`（与「下一处匹配」冲突则跟 macOS / Zed：行复制用 `⌘⇧↩` 或单独绑定，实现时钉一条并写进快捷键表）
- 行上移 / 下移：`⌥↑` / `⌥↓`（列块多选已占用 `⇧⌥↑` / `⇧⌥↓`，不要抢）
- 块注释：`⇧⌘/`，按语言选 `/* */` 或等价；整块已注释则取消
- 多光标下对每个选区生效，撤销一次回退整步

验收：快捷键表更新；单光标与多光标各走一遍复制、移动、块注释。**已落地**。行复制绑 `⇧⌘↩`（`⇧⌘D` 仍是改动视图）。

> 绑定时若与现有动作撞车，优先保住现有动作，行复制换一个空着的键，并在文档里写明。

### 6. 搜索跳转后面板不关

现在 `Enter` 打开命中处会关掉面板，逐条看要反复 `⇧⌘F`。

- 从结果打开文件后面板留着
- `↑` / `↓` 仍能换下一条；`Enter` 再跳
- `Esc` 才关
- 不在这一轮加路径过滤或搜索历史

验收：连续打开三条命中，不必重开面板。**已落地**（`Enter` 打开后面板仍是 Search；`Esc` 才关）。

### 7. 软换行开关

默认仍关。Markdown、长注释、提交说明需要时再开。

- 设置里一项：Soft wrap，默认关
- 立刻作用于已打开的缓冲
- 代码字号、行号、折叠在换行后仍对齐

验收：打开长行，打开开关后折进视口，关掉回到横向滚。**已落地**（设置 Type → Soft wrap，默认 Off，立刻作用于已打开缓冲）。

## 顺序与停手

按 1 → 7 做。做完一条，在本文勾掉，并在 `docs/开发进度.md` 记一句实现与验收。

一条如果要把 Folio 做成迷你 IDE，停下来改范围，不要接着加。
